✨ BDEmoteV1

«🎭 A custom emote experience for PocketMine-MP API 5 servers.»

BDEmoteV1 is a lightweight and stylish emote plugin designed to bring expressive player animations to your Minecraft Bedrock server.
Players can open the BDEmoteV1 Emote Menu and choose from a collection of custom emotes with dedicated resource-pack visuals.

---

🎭 Available Emotes

Emote| Description
🪑 Sit| Makes the player sit in a relaxed position.
🕴️ T-Pose| Classic T-Pose animation.
😴 Sleep| A sleeping-style player animation.
💀 Die| A defeated/death-style animation.
⚖️ Balancing| A balancing animation with the player maintaining balance.
😠 Angry| An aggressive/angry-style animation.

📦 Installation

1️⃣ Download

Download the latest BDEmoteV1 ".phar" release.

2️⃣ Install the Plugin

Place:

BDEmoteV1.phar

inside your PocketMine-MP:

/plugins/

3️⃣ Start the Server

Start or restart your PocketMine-MP server.

4️⃣ Resource Pack

BDEmoteV1 includes its required Bedrock resource-pack assets.

Make sure players accept/download the server resource pack when prompted.
